# Dustline Saloon Jukebox

An interactive web-based jukebox built with HTML5, CSS3, and vanilla JavaScript for the Dustline Saloon Trial on Hack Club Pixl.

## Screenshot

<img width="1919" height="964" alt="image" src="https://github.com/user-attachments/assets/7f0e2da8-78db-4e4c-ab87-fc4b1c262744" />

## Features
- **Custom Audio Player:** Play, pause, skip tracks, and adjust volume with live progress tracking.
- **Song Queue System:** Add multiple tracks to the queue with automatic playback progression.
- **Live Track Search:** Filter the saloon music library in real time.
- **Custom Song Requests:** Add new MP3 tracks directly to the library.
